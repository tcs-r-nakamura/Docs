# 辞書管理画面 パターン比較

以下に、AI-OCRで実際にあり得る
辞書管理画面の構成案を複数提示します。

---

# 凡例

各セクションで使う見出しの意味:

- **必須情報**
  - 辞書管理画面に存在する/載せるべき項目
- **関連実装(他画面)**
  - 辞書管理画面外で既に実装されている関連機能(参考用)
- **将来要件**
  - 辞書管理画面に追加する予定/検討中の機能
- **注意事項**
  - 実装上の制約・設計上の前提・既知の挙動など、画面利用時の留意点

---

# 辞書管理画面に必要な画面情報

辞書管理は単なる「文字置換」ではなく、OCR 後処理エンジンとして機能する画面である。

| 用途 | 例 |
| ---- | ---- |
| OCR 誤認識補正 | `O → 0` |
| 正規化 | 全角 → 半角 |
| ノイズ除去 | 改行整理 |
| 帳票依存補正 | 特定項目のみ補正 |
| Regex 補正 | パターン補正 |

---

## 1. 辞書一覧(カテゴリ管理)

### 必須情報

- 辞書名 / カテゴリ
- 辞書の有効/無効切替
- 辞書の作成・複製・削除

### 将来要件

- 辞書のインポート / エクスポート(CSV/JSON)
- 辞書のバージョン管理

---

## 2. エントリ管理(最重要)

### 必須情報

- パターン(誤認識文字 / Regex)
- 置換後の値
- 優先度
- Regex 種別(文字列 / 正規表現)
- エントリの有効/無効

### 将来要件

- 一括 CSV インポート
- 重複エントリの検出

---

## 3. 適用範囲

### 必須情報

- 全体共通適用
- テンプレート単位の適用
  - 「請求書テンプレートのみ」など
- フィールド単位の適用
  - 特定 bbox / 特定項目のみ

### 将来要件

- 帳票種別タグでのグループ適用
- 条件式による動的適用

---

## 4. テスト機能

### 将来要件

- 入力テキスト → 適用後出力のプレビュー
  - 例: 入力 `東〒京` → 出力 `東京`
- Regex のマッチ確認
- 適用順序の可視化(複数エントリヒット時)

### 注意事項

- Regex は誤マッチが業務影響に直結するため、テスト機能は必須化したい

---

## 5. confidence 連携

### 将来要件

- confidence 閾値による条件適用
  - 例: `confidence < 0.7` の項目のみ補正
- Provider 別の閾値設定

---

## 6. 適用ログ

### 将来要件

- エントリ別のヒット回数
- 直近のヒット履歴
- ヒット 0 エントリの検出(陳腐化辞書のクリーンアップ)

---

## 7. Provider 別辞書

### 将来要件

- Azure OCR 用 / Google OCR 用 / PaddleOCR 用 などの Provider 別辞書
- Provider 切替時の自動適用

### 注意事項

- Provider ごとに誤認識傾向が異なるため、共通辞書と Provider 別辞書の併用が望ましい

---

## 8. エラー / バリデーション

### 必須情報

- Regex 構文エラーの表示
- 必須項目未入力時のエラー

### 将来要件

- 適用範囲の参照整合性エラー(削除されたテンプレートを参照中、など)

---

# 辞書管理画面の代表的な画面分割

現在の実装状況・将来要件・AI-OCR 製品の実例を踏まえ、
辞書管理画面のレイアウト案を以下の 2 軸 × 3 パターンで整理する。

- **将来設計なし版**(現実装寄り) … パターン①〜③
- **将来設計あり版**(AI-OCR 完成系寄り) … パターン④〜⑥

---

## 前提整理

| 方針 | 評価 |
| ---- | -- |
| 辞書 → エントリ → 適用範囲の階層 | ◎ |
| Regex 対応 | ◎ |

| テンプレート/領域連携 | ◎ |

# 将来設計なし版(現実装ベース)

---

## パターン① 3ペイン型(UiPath 系・最推奨)

辞書一覧 → エントリ一覧 → 適用範囲の 3 ペイン。

### 画面図

```text
┌────────────┬──────────────────────┬──────────────┐
│ 辞書一覧    │ エントリ一覧          │ 適用範囲      │
│            │                      │              │
│ OCR補正     │ 有効 ☑              │ テンプレート  │
│ 全半角変換  │ パターン             │ [請求書 ▼]   │
│ 数値補正    │ 置換                 │              │
│ Regex整理   │ 優先度               │ bbox領域      │
│            │ Regex種別            │ 適用領域表示  │
└────────────┴──────────────────────┴──────────────┘
```

### 画面分割

| ペイン | 内容 |
| ---- | ---- |
| 左 | 辞書カテゴリ |
| 中央 | エントリ管理 |
| 右 | 適用範囲 |

### メリット

| 項目 | 評価 |
| ---- | -- |
| OCR 業務向き | ◎ |
| Regex 管理 | ◎ |
| テンプレート連携 | ◎ |
| 拡張性 | ◎ |

### デメリット

| 項目 | 評価 |
| ---- | -- |
| 情報量多い | △ |
| 初心者少し難しい | △ |

### 向いている

```text
・本命構成
・AI-OCR業務
・帳票OCR
```
