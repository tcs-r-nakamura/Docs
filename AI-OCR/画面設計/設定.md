# 設定画面 パターン比較（AI-OCR向け）

AI-OCRの設定画面は、

```text id="set001"
「システム設定」
```

と

```text id="set002"
「OCR運用管理」
```

のバランスが重要です。

特にAI-OCRでは：

| 一般システム | AI-OCR       |
| ------ | ------------ |
| DB設定   | OCR Provider |
| API設定  | OCR API Key  |
| Theme  | OCR使用量       |
| 接続     | OCR接続状態      |

になるため、

```text id="set003"
「AIサービス管理画面」
```

に近くなります。
