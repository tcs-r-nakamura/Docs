# 用語集 (内部値 ⇔ 画面表示名)

7 つの画面設計仕様書で参照する内部値と画面表示の対応表。
実装の正本ファイル参照を併記してあるので、揺れが発生した場合は **実装側を真** とする。

---

## ジョブステータス (`JobStatus`)

正本: `api/jobs/domain/value_objects/job_status.py:6-21`

| 内部値 (DB / API) | 画面バッジ表記 | 説明 |
| ---- | ---- | ---- |
| `queued` | 待機中 | キュー投入済、未着手 |
| `running` | 処理中 | エンジン実行中 |
| `succeeded` | ✓成功 | 正常終了 |
| `failed` | ✗失敗 | エラー終了 |
| `canceled` | キャンセル | ユーザー操作で中断 |

派生プロパティ:
- `is_terminal` = SUCCEEDED / FAILED / CANCELED のいずれか
- `is_active` = QUEUED / RUNNING のいずれか
- `is_cancelable` = `is_active` と同じ

## レビューステータス (`ReviewStatus`)

正本: `api/jobs/domain/value_objects/review_status.py:1-15`

| 内部値 (DB / API) | 画面バッジ表記 | 説明 |
| ---- | ---- | ---- |
| `unreviewed` | 未確認 | 未レビュー (docstring は「未レビュー」だが UI 表示は「未確認」) |
| `completed` | 完了 | レビュー完了 (テキスト修正なし) |
| `completed_with_edit` | 修正完了 | レビュー完了 (テキスト修正あり) |

注意:
- `unreviewed` の docstring (「未レビュー」) と UI バッジ表記 (「未確認」) で揺れあり。
  実装側を変更しない場合は仕様書の「未確認」表記に統一すること。

## OCR エンジン (Provider / Engine)

正本:
- **画面表示 / API 取得**: `scripts/init/engines.json` (seed データ。`EngineGatewayAdapter.cs:34` 経由で UI へ供給)
- **ランタイム実行**: `api/jobs/infrastructure/engines/engine_registry.py:27-34`

### Provider 一覧 (7 種)

| 内部値 | 画面表記 | クレデンシャル | 備考 |
| ---- | ---- | :----: | ---- |
| `mock` | mock | 不要 | テスト用 |
| `azure` | Azure | 必要 | Document Intelligence |
| `google` | Google | 必要 | Document AI |
| `paddleocr` | PaddleOCR | 不要 | ローカル実行 |
| `yomitoku` | YomiToku | 必要(本番) | License Key、開発モードは不要 |
| `gemini` | Gemini | 必要 | API Key |
| `qwen` | Qwen | 必要 | Endpoint。API Key は任意 (ローカル vLLM/Ollama 用) |

### Engine 一覧 (8 種、seed 表記)

`scripts/init/engines.json` の `{provider_code}/{code}` 形式に準拠。

| エンジンコード | Provider | code | 必須クレデンシャル |
| ---- | ---- | ---- | ---- |
| `mock/default` | mock | default | - |
| `azure/document-intelligence` | azure | document-intelligence | endpoint, api_key |
| `google/document-ai` | google | document-ai | service_account_json, project_id, location, processor_id |
| `paddleocr/PP-OCRv5` | paddleocr | PP-OCRv5 | - |
| `yomitoku/DocumentAnalyzer` | yomitoku | DocumentAnalyzer | - (本番は license_key) |
| `gemini/3.1-pro` | gemini | 3.1-pro | gemini_api_key |
| `gemini/3.1-flash-lite` | gemini | 3.1-flash-lite | gemini_api_key |
| `qwen/vl-ocr` | qwen | vl-ocr | qwen_vl_endpoint (api_key は任意) |

必須キー正本: `scripts/init/engines.json` の `required_credentials`
WPF 送信対応: `ProviderCredentialMap.cs` — 現状 azure / google / yomitoku のみ
⚠️ gemini / qwen は seed/API には登録あるが WPF から実行不可

## 信頼度バンド

OCR 結果の `confidence` を 4 段階に色分け。

| 値域 | バンド | bbox 色 |
| ---- | ---- | ---- |
| ≥ 0.9 | 高 | 緑 |
| ≥ 0.7 | 中 | 黄 |
| < 0.7 | 低 | 赤 |
| null | 不明 | 青 |

結果確認画面の中央ペイン bbox 表示と右ペインのテキストブロック背景色に反映。

## 凡例

各画面設計仕様書で共通的に使用される記号:

| 記号 | 意味 |
| ---- | ---- |
| ◎ | 強み・優れている |
| ○ | 普通・適切 |
| △ | 弱み・課題あり |
| × | 非対応・未実装 |
| ⚠ | 警告・注意 |
| ● | 動作中・正常稼働 |
| ☑ / ☐ | チェック済 / 未チェック |
| ✎ | 編集モード |
| ↶ ↷ | Undo / Redo |
| ⟳ | リフレッシュ / リセット |
| ＋ / × | 追加 / 削除 |
