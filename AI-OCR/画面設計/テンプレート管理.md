# テンプレート管理画面 パターン比較

以下に、AI-OCRで実際にあり得る
テンプレート管理画面の構成案を複数提示します。

---

# 凡例

各セクションで使う見出しの意味:

- **必須情報**
  - テンプレート管理画面に存在する/載せるべき項目
- **関連実装(他画面)**
  - テンプレート管理画面外で既に実装されている関連機能(参考用)
- **将来要件**
  - テンプレート管理画面に追加する予定/検討中の機能
- **注意事項**
  - 実装上の制約・設計上の前提・既知の挙動など、画面利用時の留意点

---

# テンプレート管理画面に必要な画面情報

テンプレート管理は単なる「画像編集」ではなく、OCR 読み取り定義(帳票解析ルール)を作成する画面である。

| 項目 | 内容 |
| ---- | ---- |
| 会社名 | この位置 |
| 金額 | この位置 |
| 日付 | この位置 |
| 明細 | この範囲 |

を bbox として定義する。

---

## 1. テンプレート一覧

### 必須情報

- テンプレート名
- 抽出領域数(例: `5 領域`)
- 作成日 / 更新日
- 複製・削除

### 将来要件

- 帳票種別タグ(請求書 / 名刺 / 申請書 …)
- 検索・絞り込み
- インポート / エクスポート

---

## 2. 領域エディタ(Canvas)(最重要)

### 必須情報

- サンプル帳票画像の表示
- 矩形(bbox)の作成・編集・削除
- 領域選択
- 複数領域の表示

### 将来要件

- Zoom / Pan / Fit Width
- 100% 表示切替
- 矩形のスナップ(端揃え)
- 多角形領域・テーブル領域の対応

### 注意事項

- 中央が主役(画像編集が主作業)であるため、Canvas を主領域に置くべき

---

## 3. 領域詳細設定

### 必須情報

- 項目名(会社名 / 金額 など)
- OCR 種別
  - 全文 / 数値 / 日付 / 金額 / Barcode 等
- 必須/任意フラグ
- Regex バリデーション
- confidence 閾値

### 将来要件

- AI 補助(「これは請求金額ですか？」など)
- 候補値リストの定義
- 後続フィールドへの値依存設定

---

## 4. bbox 連動

### 必須情報

- 矩形クリック → 右ペインの該当項目をハイライト
- 項目選択 → 該当矩形をハイライト

### 将来要件

- 選択中矩形の OCR テスト実行

---

## 5. OCR 種別

### 必須情報

- 全文(プレーンテキスト)
- 数値
- 日付
- 金額
- バーコード / QR

### 将来要件

- 手書き文字
- 表(行列構造)

---

## 6. confidence 閾値設定

### 将来要件

- フィールド単位の閾値
- 閾値未満は結果確認画面で要レビュー扱い

---

## 7. AI 補助

### 将来要件

- AI による領域自動検出
  - 「請求金額」「日付」など意味推定
- AI 候補の採用/却下
- テンプレート自動生成(サンプル画像から)

### 注意事項

- AI 補助はあくまで候補提示、最終決定は人が行う設計が望ましい

---

## 8. Zoom / Pan

### 将来要件

- + / -
- Fit Width / Fit Page
- 100% 表示
- Pan(スペース + ドラッグ)

---

## 9. テンプレートテスト

### 将来要件

- サンプル帳票で OCR を試行し、各領域の結果を即時確認
- bbox ズレ / Regex 未マッチの検出

---

# テンプレート管理画面の代表的な画面分割

現在の実装状況・将来要件・AI-OCR 製品の実例を踏まえ、
テンプレート管理画面のレイアウト案を以下の 2 軸 × 3 パターンで整理する。

- **将来設計なし版**(現実装寄り) … パターン①〜③
- **将来設計あり版**(AI-OCR 完成系寄り) … パターン④〜⑥

---

## 前提整理

| 方針 | 評価 |
| ---- | -- |
| 中央 Canvas が主役 | ◎ |
| 左にテンプレ一覧 | ◎ |
| 右に領域詳細 | ◎ |
| bbox 連動 | ◎ |
| OCR 種別の選択肢を持つ | ◎ |
