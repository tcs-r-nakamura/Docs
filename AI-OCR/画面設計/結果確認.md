# 結果確認画面 パターン比較

以下に、AI-OCRで実際にあり得る
結果確認画面の構成案を複数提示します。

---

# 凡例

各セクションで使う見出しの意味:

- **必須情報**
  - 結果確認画面に存在する/載せるべき項目
- **関連実装(他画面)**
  - 結果確認画面外で既に実装されている関連機能(参考用)
- **将来要件**
  - 結果確認画面に追加する予定/検討中の機能
- **注意事項**
  - 実装上の制約・設計上の前提・既知の挙動など、画面利用時の留意点

---

# 結果確認画面に必要な画面情報

---

## 1. 処理一覧/履歴(最重要)

### 必須情報

- 過去のOCR処理ジョブ一覧
- ファイル名 / 処理日時 / ステータス
- レビュー状態(未確認 / 確認済 / 編集して確認済)
- ジョブ選択で結果を読み込み

### 将来要件

- 未確認 / エラー / 帳票種別での絞り込み
- 大量履歴向けのページング・仮想スクロール

---

## 2. 原本画像プレビュー(最重要)

### 必須情報

- 原本画像の表示
- bounding box の重畳表示
- ページ送り(複数ページ PDF 対応)
- bbox 選択時の右ペイン項目フォーカス連動

### 将来要件

- Zoom / Pan / Fit Width
- bbox 表示/非表示切替
- 領域選択での手動再 OCR

---

## 3. OCR結果表示・編集

### 必須情報

- 抽出テキストブロック一覧
- ブロック単位での編集
- 各ブロックの ReviewStatus 表示(未確認 / 確認済 / 編集して確認済)
- 編集確定で OCR 結果差し替え

### 関連実装(他画面)

- レビュー状態は `IReviewStateGatewayPort` 経由で永続化

### 将来要件

- 編集前後の差分表示
- Undo / Redo
- 編集理由のメモ

---

## 4. confidence表示

### 必須情報

- 各テキストブロックの confidence 値
- 閾値未満項目のハイライト

### 将来要件

- 画面側での confidence 閾値設定
- 低 confidence のみ絞り込み

---

## 5. 一括レビュー操作

### 必須情報

- 「未確認をすべて確認済にする」一括操作
- レビュー状態の永続化

---

## 6. 検索・フィルタ

### 必須情報

- ファイル名・抽出テキストでの検索
- レビュー状態によるフィルタ

### 将来要件

- 処理日範囲・帳票種別での絞り込み
- confidence 範囲での絞り込み

---

## 7. 出力・コピー

### 必須情報

- 結果テキストのクリップボードコピー
  - コンテキストメニュー / `Ctrl+C`

### 将来要件

- JSON / CSV / Excel エクスポート
- 保存先指定(ファイルシステム / 外部システム連携)

### 注意事項

- 現状は結果データのエクスポート設定を持たない
- エクスポート機能の配置先(本画面 or OCR 実行画面)は要検討

---

## 8. ステータス・処理情報

### 必須情報

- 処理日時
- 使用 Provider / Engine
- 適用テンプレート
- 処理時間 / ページ数

### 将来要件

- 個別ジョブのコスト表示
- 校正(`ProofreadingId`)の適用有無

### 注意事項

- 「校正」(`ProofreadingId`)は OCR 実行時にサーバー側で適用される自動補正
- 結果画面の「レビュー」(`ReviewStatus`)とは別概念

---

## 9. エラー表示

### 必須情報

- ジョブ失敗時のエラーメッセージ表示
- 失敗ジョブの再実行導線

### 将来要件

- カテゴリ別アイコン・色分け
- 失敗箇所の bbox 強調

---

# 結果確認画面の代表的な画面分割

現在の実装状況・将来要件・AI-OCR 製品の実例を踏まえ、
結果確認画面のレイアウト案を以下の 2 軸 × 3 パターンで整理する。

- **将来設計なし版**(現実装寄り) … パターン①〜③
- **将来設計あり版**(AI-OCR 完成系寄り) … パターン④〜⑥

---

## 前提整理

| 方針 | 評価 |
| ---- | -- |
| 原本画像が主役 | ◎ |
| OCR 編集を右ペインに分離 | ◎ |
| レビュー状態の可視化 | ◎ |
| bbox 連動 | ◎ |
| 出力設定は本画面に持たない | ◎ |

---

# 将来設計なし版(現実装ベース)

---

## パターン① 2ペイン型(DX Suite 系)

シンプル業務向け。

### 画面図

```text
┌──────────────────────────┬────────────────┐
│ 原本画像                  │ OCR結果編集     │
│                          │                │
│ ┌────────────────────┐   │ 項目名         │
│ │ bbox               │   │ OCR結果        │
│ │                    │   │ 修正値         │
│ │                    │   │ confidence     │
│ └────────────────────┘   │                │
│                          │ [保存]         │
└──────────────────────────┴────────────────┘
```

### 画面分割

| 領域 | 内容 |
| ---- | ---- |
| 左 60% | 原本 + bbox |
| 右 40% | OCR 編集 |

### メリット

| 項目 | 評価 |
| ---- | -- |
| シンプル | ◎ |
| 学習コスト低い | ◎ |
| OCR 確認しやすい | ◎ |

### デメリット

| 項目 | 評価 |
| ---- | -- |
| 履歴管理弱い | △ |
| 大量処理弱い | △ |

### 向いている

```text
・中小規模OCR
・単発確認
・初心者
```

## パターン② 3ペイン型(UiPath 系・最推奨)

履歴 + 原本 + 編集の 3 ペイン。AI-OCR 業務で最強。

### 画面図

```text
┌────────────┬──────────────────────────┬──────────────┐
│ 処理一覧    │ 原本画像                  │ OCR結果編集   │
│            │                          │              │
│ 🔍検索      │ ┌────────────────────┐   │ 項目名       │
│            │ │ bbox               │   │ OCR結果      │
│ 未確認 12  │ │                    │   │ confidence   │
│ 完了 40    │ │                    │   │ 修正値       │
│ エラー 2   │ └────────────────────┘   │              │
│            │                          │ [保存]       │
└────────────┴──────────────────────────┴──────────────┘
```

### 画面分割

| 領域 | 内容 | 推奨幅 |
| ---- | ---- | ---- |
| 左 | 一覧・検索・状態 | 240〜300px |
| 中央 | 原本画像 + bbox | 50〜60% |
| 右 | OCR 編集 | 320〜400px |

### メリット

| 項目 | 評価 |
| ---- | -- |
| 修正効率 | ◎ |
| 次案件へ進みやすい | ◎ |
| AI-OCR 業務向き | ◎ |

### デメリット

| 項目 | 評価 |
| ---- | -- |
| 情報量多い | △ |
| 小画面厳しい | △ |

### 向いている

```text
・AI-OCR本命
・業務OCR
・毎日大量確認
```
