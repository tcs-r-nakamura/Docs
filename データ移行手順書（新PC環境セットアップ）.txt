 データ移行手順書（新PC環境セットアップ）
  
  前提

  - 新PC: Windows（WSL2 + NixOS-WSL 構成）
  - 旧PCからコピーが必要なもの: SSH秘密鍵、NixOS設定ファイル、.env/.env

  ---
  Step 1: Windows側 — WSL2 の有効化

  管理者権限の PowerShell で実行:

  wsl --install --no-distribution
  # 再起動後に続行

  ---
  Step 2: NixOS-WSL のインストール

  1. NixOS-WSL の最新リリースから nixos-wsl.tar.gz をダウンロード
    - リリースページ: https://github.com/nix-community/NixOS-WSL/releases
  2. WSL へインポート:

  wsl --import NixOS "$env:USERPROFILE\NixOS" nixos-wsl.tar.gz --version 2
  wsl -d NixOS

  ---
  Step 3: NixOS 設定ファイルの移行
  
  旧PCで /etc/nixos/ 以下の4ファイルを新PCへコピーする:

  /etc/nixos/flake.nix
  /etc/nixos/flake.lock
  /etc/nixos/configuration.nix
  /etc/nixos/home.nix

  新PCの NixOS で配置後、適用:

  sudo nixos-rebuild switch --flake /etc/nixos#nixos

  適用後に含まれるツール: git, gh, tmux, ripgrep, fd, fzf, jq, nodejs_22, uv, chromium, devenv, direnv, docker

  ---
  Step 4: SSH 鍵の移行
  
  旧PCから以下を新PCへコピー（パーミッション設定も必須）:

  # 新PC側で実行
  mkdir -p ~/.ssh
  # 旧PCから転送後:
  chmod 700 ~/.ssh
  chmod 600 ~/.ssh/id_ed25519
  chmod 644 ~/.ssh/id_ed25519.pub

  ~/.ssh/config を作成:

  Host wsl
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

  chmod 600 ~/.ssh/config
  # GitHub に接続確認
  ssh -T git@github.com

  ---
  Step 5: GitHub CLI 認証

  gh auth login
  # → GitHub.com → SSH → id_ed25519.pub を選択 → ブラウザで認証

  ---
  Step 6: プロジェクトの clone

  mkdir -p ~/projects
  cd ~/projects
  git clone git@github.com:tcs-s-organization/tcs-ocr.git
  cd tcs-ocr

  ---
  Step 8: devenv 環境の構築

  cd ~/projects/tcs-ocr
  # .envrc が devenv shell を自動起動する
  direnv allow
  # 初回は Nix パッケージのダウンロードに数分かかる

  # Python venv の構築
  uv sync --all-extras

  ---
  Step 9: DB のマイグレーション

  # devenv のプロセスを起動（PostgreSQL + API + db-init が立ち上がる）
  devenv up
  # 別ターミナルで確認
  set -a && source .env/.env && set +a
  python -m pytest api/tests/unit/ -v

  ---
  Step 10: Claude Code のインストール

  npm install -g @anthropic-ai/claude-code

  Claude Code の設定を復元（~/.claude/settings.json）:

  {
    "enabledPlugins": {
      "pyright-lsp@claude-plugins-official": true,
      "csharp-lsp@claude-plugins-official": true
    },
    "model": "sonnet"
  }

  ---
  Step 11: .NET SDK の確認
  
  devenv.nix の publish-client スクリプトが dotnet を使用します。現在のバージョンは 10.0.201 です。NixOS 設定に含まれていない場合は home.nix の home.packages に dotnet-sdk_10 を追加して nixos-rebuild switch
  を再実行してください。
